## Build it yourself
```bash
docker build -t my-comfy-workflow .
docker run --rm --gpus all -p 8188:8188 my-comfy-workflow
```
If the workflow uses gated HuggingFace or CivitAI models, pass tokens at build time:
```bash
docker build --build-arg HF_TOKEN=$HF_TOKEN --build-arg CIVITAI_API_KEY=$CIVITAI_API_KEY -t my-comfy-workflow .
```
## Deploy on Runpod
1. Connect this repository at https://runpod.io/console/serverless
2. Create a new endpoint, select **Deploy from GitHub**
3. Pick this repo, branch `main`
4. Runpod's builder will build the Dockerfile and host the resulting image
5. Hit the endpoint with the API workflow JSON (`api-workflow.json` in this repo)

The GitHub builder kills Docker builds after **30 minutes**. The 32GB UNET plus
32B text encoder cannot be baked into the image. The Dockerfile only installs
nodes and small files (LoRAs, VAEs). The two large weights download on the
**first worker boot** (or are skipped if they already exist on a network volume
under `/runpod-volume/models`). Give the worker ~80 GB container disk and a
long startup/execution timeout. To skip first-boot download, attach a network
volume that already contains those files.

The yellow `runpod.serverless.start() handler not found` banner on create is a
GitHub search-index false alarm. `handler.py` is on `main`.
